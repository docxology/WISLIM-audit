# WISLIM-audit documentation

The [manuscript](manuscript/README.md) presents the audit’s analysis of
the argument, formal claims, and stated evidence in the published WISLIM
paper. Individual findings are recorded as observations with stable IDs.

- [Method](method.md) explains the source and observation standards.
- [Claim index](claims.md) and [stress-test index](stress-tests.md) describe
  the evidence ledgers. The [glossary](glossary.md) defines terms used in the audit.
- [Issue register](audit/README.md) lists the generated observations.
- [External review index](reviews.md) lists the separate review records.
- [Local verification](reproducibility.md) covers checksums, line numbering,
  register validation, and tests.
- [Build the manuscript](manuscript-build.md) covers PDF and HTML.

The [source provenance](../evidence/provenance.md) identifies the immutable PDF
and text extraction. Original analytical notes, evidence files, and external
review records remain at their source and archive paths to preserve existing
citations and register links. The [historical workflow review](archive/workflowz-review.md)
records an earlier inspection with a narrower scope.
