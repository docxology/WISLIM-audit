# WISLIM-audit

An independent textual audit of David Wishengrad’s *Life is Most Important in
Life is The Most Important Truth in Life*, version 2.0.1, dated 4 February 2026.
The contributors examine what the published argument establishes and what
evidence would be needed for its stronger conclusions.

**Audit verdict — revise, do not adopt.** The audit treats the protection of
life and agency as a serious concern. It finds that the paper’s argument for
universal, overriding priority requires a further normative premise.

Start with the [documentation](docs/README.md) or the
[manuscript](docs/manuscript/README.md). The [issue register](docs/audit/README.md)
contains 66 records under `docs/audit/`. Each is an audit observation, not a required fix.
The archived source extraction has 13,255 newline-delimited lines.

Run `make verify` with Python 3.11 or later to check the local source, model
records, generated registers, and tests. The
[verification guide](docs/reproducibility.md) explains the evidence checks.
The [license](LICENSE) covers the audit text. The
[source provenance](evidence/provenance.md) records the audited work’s own terms.
