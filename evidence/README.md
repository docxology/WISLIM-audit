# Evidence

This directory records the provenance and external evidence for the audit.

| File | Contents |
|---|---|
| `provenance.md` | PDF and text hashes, extraction method, line numbering, version labels, license ambiguity, missing materials. |
| `philpapers.md` | The PhilPapers record, categories, references, download/citation counts, and what the record does and does not show. |
| `citation-audit.md` | A reference-by-reference audit of Appendix C and the paper's citation practice. |
| `ai-letter-audit.md` | A methodological audit of the seven AI letters in Appendix B. |

## Standards

- External claims are dated and linked.
- Hash and line-count checks are reproducible with standard tools.
- The audit distinguishes what the record shows from what it does not show.
- Missing evidence is recorded as missing, not inferred.
- The source paper is not redistributed outside the private repository.
